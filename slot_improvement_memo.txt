スロット設定推測アプリ 改善案メモ v1

■ 目的 思いつきメモを整理し、実装・設計に使える形にする

■ 天井機能 ・単位ラベルはjson管理（G / WAVE / 周期 / あべし / pt）
・天井種別：GAME / COUNT / CYCLE / POINT / COMPOSITE
・スルー回数はCOUNTで統一（専用実装しない）
・非搭載機種は「天井機能：非搭載」と表示 ・天井欄は折りたたみ
・複数天井はconditions配列で管理 ・恩恵はjsonから取得
・リセット情報もjsonで管理

■ 入力仕様 ・GAME / POINT → TEXT入力 ・COUNT / CYCLE → STEPPER入力
・GAME / POINTの0は未入力扱い（null） ・未入力は「ー」表示
・到達時は「到達済み」 ・最大値はinputMaxで制御

■ UI仕様 ・isPrimaryで代表条件 ・displayOrderで表示順
・isHighlightedで強調 ・攻略リンクは上部表示
・折りたたみ時は代表条件のみ表示

■ セッション連携 ・conditionId + currentValueで保存
・グラフは実践完了時に反映

■ 拡張予定 ・メモ機能 ・小役カウンター ・重複ボーナス入力 ・スリープ防止
・自由カウンター（後回し）

■ 不具合 ・0入力問題 ・グラフ未反映

■ 将来 ・ボーナス中小役カウント ・期待値機能

■ 重要方針 ・天井はjsonで管理 ・COUNTで回数系統一
・0は未入力ではない（null） ・UIは折りたたみ前提 ・COMPOSITEは後回し
